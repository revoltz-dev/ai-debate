# Artwork

`app.png` is the application logo and favicon. Provider artwork is selected from `claude.png`, `codex.png`, `gemini.png`, or `other.png` according to each agent's type. When an image cannot be loaded, the interface renders a colored fallback with the agent's initial.

The provider names and marks belong to their respective owners. Their inclusion identifies supported agent types and does not imply affiliation or endorsement.
